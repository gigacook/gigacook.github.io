# 03 — FAILURE TRIGGERS (autismfinal)

Träffas något av detta → **FAIL**. Inga ursäkter. Inga förklaringar.
Vid FAIL: säg "FAIL" + det dödliga felet i en mening, kör korrektionsloopen, börja om beatet.

---

## GLOBALA INSTANT-FAILS
- Hoppar över ABCDE när patienten är instabil.
- Går vidare till B innan A är säkrad.
- Ordinerar utan att ha en arbetsdiagnos.
- "Avvaktar" / "skickar hem" en instabil eller röd-flagg-patient.
- Vägrar ta ställning. Frågar tillbaka istället för att svara.
- Ren teori utan handläggning.

## ANESTESI
- Maskventilerar vid RSI.
- Ger naloxon/sugammadex utan att säkra luftväg först.
- Häller kristalloid i blödningschock istället för blod (4:4:1).
- Pumpar upp BT vid okontrollerad blödning.
- Glömmer kalcium vid massiv transfusion.

## KIRURGI
- Oral kontrast eller exspektans vid brädhård buk / fri gas.
- Avstår antibiotika vid kolangit / perforation / strangulation.
- Opererar inte vid strangulationstecken i ileus.
- Reponerar ett misstänkt strangulerat bråck.
- Övertransfunderar GI-blödning (Hb-mål överskrids).
- Kallar melena "nedre GI-blödning".
- Missar U-hCG hos fertil kvinna med buksmärta.

## KÄRL
- Förväxlar emboli och trombos och ger fel behandling.
- Försöker reperfundera ett irreversibelt (rigor, marmorerat, inget venljud) ben.
- Tar CT på en instabil RAAA.
- Avskriver ischemi hos diabetiker pga "normalt/högt ABI" utan tåtryck.
- Litar på normalt laktat för att utesluta mesenteriell ischemi.
- Väntar på pulsbortfall innan kompartmentsyndrom åtgärdas.

## ONKOLOGI
- Väntar på odlingssvar innan Ab vid neutropen feber.
- Ger G-CSF akut vid neutropen feber.
- Beställer bara MR ländrygg vid misstänkt medullakompression.
- Skjuter upp kortison vid medullakompression.
- Påstår att mastektomi ger bättre överlevnad än bröstbevarande + strålning.

## ORTOPEDI
- Skickar hem cauda equina / kompartmentsyndrom som "lumbago" / "vanlig smärta".
- Ger antibiotika före ledpunktion vid septisk artrit.
- Punkterar en protesled på VC/akuten.
- Högläge vid kompartmentsyndrom.
- Skruvar en dislocerad cervikal höftfraktur (Garden III–IV).

## ENDOKRIN
- Avvaktar / beställer DT vid tilltagande stridor + halssvullnad postop (öppna såret!).
- Avfärdar postop stickningar/handkramp som ångest (= hypokalcemi).
- Tar all paratyreoideavävnad utan autotransplantat.
- Tolkar högt Ca utan att kontrollera PTH.

## HAND
- Lokalbedövar FÖRE distalstatus.
- Syr bara huden och skickar hem trots sen-/nervskada.
- Avvaktar med op vid klinisk purulent tendovaginit (Kanavels tecken).
- Hoppar över rengöring/debridering.
- Bryter ordningen: hygien → rengöring → anestesi → debridering → suturering.
