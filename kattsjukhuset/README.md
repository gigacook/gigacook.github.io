# 🐾 Kattsjukhuset

Ett gulligt 3D-kattsjukhus i webbläsaren – i gammal flash-spelsanda. Du är en katt. Alla är läkarstudenter.

**Spela:** https://gigacook.github.io/kattsjukhuset/

- 🎧 Kontor med headset-katter vid datorer
- 🩺 Avdelning med patienter i sängar, dropp och telemetri
- 🚨 IVA med 3 sängar och helt överdrivna maskiner
- 📊 Stora väggskärmar med live-statistik
- 💌 Bjud in riktiga vänner – de väljer namn, storlek, färg och klädsel och dyker upp i realtid (WebRTC via PeerJS)

Styr: WASD/pilar eller klicka · Mellanslag hoppa · Enter chatta · M mjau.

Byggt med three.js + PeerJS, en enda `index.html`.
